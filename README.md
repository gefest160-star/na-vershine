# На вершине

Нуар-история в пяти главах о человеке, который хотел подняться наверх. Low-poly 3D, вид от третьего лица, озвученные диалоги. Сделана на Godot 4.7.

## Как запустить

- **Проще всего:** двойной клик по `run.bat`.
- **Через редактор:** открыть Godot → «Импортировать» → выбрать `project.godot` → нажать F5.

Игра стартует на весь экран. F11 переключает оконный режим, Esc открывает меню.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | ходить |
| Shift | бежать |
| мышь (зажать и тянуть) или ← → | вращать камеру |
| колёсико | приблизить / отдалить |
| E | действовать, говорить, входить в двери |
| Пробел / клик | следующая реплика |
| 1–3 | выбор ответа |
| Esc | меню (громкость, озвучка, начать заново) |

Золотой ромб показывает, куда идти. Прогресс сохраняется в начале каждой главы.

## Что где лежит

| Путь | Что это |
|---|---|
| `scripts/story.gd` | весь сюжет: главы, этапы, реплики, выборы, постановочные сцены |
| `scripts/levels.gd` | все 11 локаций; вид зависит от главы |
| `scripts/game.gd` | ядро: камера, погода, переходы, сохранение, отладочные режимы |
| `scripts/human.gd` | персонажи из примитивов с процедурной анимацией |
| `scripts/build.gd`, `furn.gd` | стены с окнами, мебель, реквизит |
| `scripts/ui.gd`, `audio.gd` | интерфейс и звук |
| `audio/` | музыка, эффекты, озвучка (317 реплик) |
| `tools/` | инструменты: озвучка, звуки, проверки (движок эту папку не читает) |

## Если меняете текст реплик

Озвучка привязана к тексту. После правки `scripts/story.gd`:

```
tools\.venv\Scripts\python tools\gen_voice.py
```

Скрипт озвучит только новые и изменённые реплики (нужен интернет). Потом один раз откройте проект в редакторе Godot — он подхватит новые файлы.

Голос персонажа меняется в таблице `CAST` в начале `tools/gen_voice.py`; после замены перегенерируйте его реплики: `gen_voice.py --only patron --force`. Проверить результат: `tools\.venv\Scripts\python tools\check_voice.py`.

## Проверки (для разработки)

```
powershell tools\check.ps1 -GameArgs "--autoplay","--flavor"   # прогон всего сюжета без окна
powershell tools\check.ps1 -GameArgs "--reach"                  # до всех точек можно дойти
powershell tools\check.ps1 -GameArgs "--bot","--ch=1"           # бот проходит игру нажатиями клавиш
```

Запуск с конкретного места: `godot --path . -- --ch=3 --stage=2`.
